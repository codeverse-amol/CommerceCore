Consistent local + EC2 deployment, our target will be:

CommerceCore
│
├── Dockerfile              ← Django/Gunicorn image
├── docker-compose.yml      ← Django + MySQL + Redis + Celery + Nginx
├── .dockerignore
├── .env                    ← environment-specific values
└── ...
